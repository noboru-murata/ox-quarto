** callout
- 大きさは Quarto の html と同じく周りの文字と同じ (~$callout-font-size: 1em~)．revealjs の既定 0.7em は打ち消した．
  1 つだけ変えるときは ~:class "text-85"~．Quarto 1.10 はこのクラスを callout の外側の div に移すので，両方に効く CSS にしてある．
- 見出しの帯は全 palette で色付き: ~mix(枠の色, 地の色, $callout-title-tint=12%)~．
- 種類なしの callout (~#+begin_callout :title "…"~) は Quarto では帯のない simple 型になるので，typed と同じ見た目に揃えた．
- 本文の余白: 上 ~$callout-body-gap-top: 0.3em~ ＜ 下 ~0.45em~ (地の文と箇条書きで揃える．Quarto の ~p { margin-top: 0.7em }~ を打ち消す)．
- 帯の無い callout (種類なしの ~callout~ と，題の無い ~callout-*~ の minimal) の余白 (2026-10-13): 上下を同じ ~$callout-untitled-gap~ (既定 0.45em) に．
  前は段落の上に Quarto の 0.7em が残り下は 0 で，文字が下に寄っていた (上 13px・下 1px)．最初の子の上の余白と，最後の子 (箇条書きなら最後の項目) の
  下の余白を消す．段落 1 つ・2 つ，箇条書き，段落 + 箇条書きで上下 13〜15px に揃うことを確かめた．
  あわせて題付きの callout も，箇条書きで終わるときに最後の項目の下の余白が残っていた (下 20px) のを消した (段落と同じ 14px 前後)．
- 問題文の callout には「＝」を含む式を入れず，callout の下に数式ブロックで書く (読みやすさ)．
- アイコン (2026-10-13): 空でない ~:title~ を付けた callout は，~:icon~ を書かなければ ox-quarto-ext (ox-quarto-ext-block.el) が
  ~icon="false"~ を足す．講演・講義の callout は題付きのものがすべて ~:icon false~ だった (piml 53/53，talk-sample 9/9) ので既定にした．
  形式 (revealjs / html / pdf / typst) によらず同じ．残すなら ~:icon true~ (~#+ATTR_QUARTO:~ でも)．題が無い・空 (~""~ や空白だけ) ならそのまま．
  止めるには ~ox-quarto-ext-callout-title-icon~ を t に．構造テンプレート (~<cn~ など) からは ~:icon false~ を外した．
  サンプル: talk-sample / slide-sample の ~:icon false~ は外した．
- 題なしの帯 (2026-10-13): 種類付きの callout は題が無くても帯に既定の題 (lang: ja で「ノート」「警告」など) とアイコンを出す．
  帯なしは種類なしの ~callout~ (simple) だけだった．種類の色で帯なしの枠にするには Quarto の ~appearance="minimal"~
  (simple は本文の行頭にアイコンが残る．~title=""~ は既定の題の帯になる)．
  そこで題の無い ~callout-*~ は，~:appearance~ と ~:icon true~ が無ければ ox-quarto-ext が ~appearance="minimal"~ を足す．
  Quarto の既定の形 (帯に既定の題とアイコン) は ~:icon true~ で．止めるには ~ox-quarto-ext-callout-untitled-minimal~ を nil に．
  講演・講義のサンプルと piml の callout はすべて題付きなので見た目は変わらない．

** #+QUARTO_<FORMAT>_OPTIONS で yaml のリストが消える (2026-10-13)
- 症状 (ISSUES.md，physics-informed_ml): ~#+QUARTO_REVEALJS_OPTIONS: csl:piml-apa.csl~ を足すと，qmd の ~format: revealjs:~ の
  ~theme:~ と ~include-in-header:~ が空になり，Quarto が「Field "theme" has empty value」で止まる．
- 原因: ox-quarto 本体 (~org-quarto-yaml-frontmatter~) は ~#+QUARTO_<FORMAT>_OPTIONS~ があると yaml の ~format:~ を
  ~org-quarto--strip-and-parse-format-block~ で読み直して組み立て直す．この読み方は「    key: value」の 1 行しか扱わず，
  リストの行 (~      - 項目~) と行末のコメントを落とす．
- 対処 (本体は変えない): ~lisp/ox-quarto-ext/ox-quarto-ext-format.el~．options フィルタで，front matter の yaml があれば
  ~#+QUARTO_<FORMAT>_OPTIONS~ の各 key を ~format:~ の形式の中に「    key: value」で置く (同じ key はリストの値ごと置き換え，
  無ければ足す．~format:~ や形式の行が無ければ作る)．書き込んだキーワードは parse-tree フィルタで木から外し，本体の読み直しを通さない．
  yaml が無ければ本体に任せる (この場合はリストが無いので壊れない)．key:value の区切り方は本体の ~org-quarto--parse-opts-str-to-alist~．
- 確かめたこと: talk.org + ~csl:… slide-number:false~ と ~theme:[default,x.scss]~ と ~#+QUARTO_HTML_OPTIONS: toc:true~ で，
  include-in-header のリストとコメントが残り，theme は置き換わり，html の形式が足される．~format:~ は 1 つだけ．
  ~csl~ を形式の中で apa.csl にすると talk.yaml の apa-short.csl より優先される (6 名の文献が全員になる) ことも見た．
  yaml の無い org では本体のとおり ~format: html: toc: true~．
- 上流 (jrgant/ox-quarto) に報告する価値がある．

** 横長の図: .fig-short (2026-10-10)

* 文献

- 書式は ~_quarto/csl/apa.csl~ (本文は (著者, 年))．org では ~[cite:@key]~ / ~[cite/t:@key]~．
- スライド (talk.yaml / lecture.yaml) は ~_quarto/csl/apa-short.csl~ (2026-10-13．ISSUES.md の要望)．apa.csl の文献一覧だけを変えたもの:
  3 名までは全員，4 名以上は最初の 2 名 + et al. (apa.csl は 20 名まで全員)．本文の (著者 et al., 年) は APA のまま．

  apa.csl は Zotero のスタイル集の CC BY-SA 3.0 なので，apa-short.csl も title・id を変え，元への link (template) とライセンスを残した．
  6 名・4 名・3 名・1 名の文献で，一覧が「Cranmer, M., Greydanus, S., et al. (2020)」などになることを確かめた．
- ~lib/cite-aside.lua~: スライドごとに引用した文献の書誌をそのスライドの脚注欄に出す．
  - 書誌全体を doi / url へのリンクにし (新しいタブ)，doi の文字列は出さない．
  - ~cite-aside-max~ (talk / lecture は 2) より多く引用したスライドでは出さない．~{.no-cite-aside}~ / ~{.cite-aside}~．

* 解説文 (report / handout)
- 2026-10-08: ~report-latex~ / ~report-typst~ (解説文) と ~handout-latex~ / ~handout-typst~ (Tufte 形式) を置いた．
  ~report.{org,yaml}~ は report-latex へ，~handout.{org,yaml}~ は handout-latex へのリンク (既定は LaTeX)．
- report-typst / handout-typst: typst は文献の一覧を最後に自分の見出し ("Bibliography") 付きで出すので ~#set bibliography(title: none)~．
  csl のパスの ~_~ を扱えないので，csl は html だけ，typst は内蔵の apa (bibliographystyle)．
- report-latex / handout-latex: documentclass scrartcl，日本語は luatexja-preset．csl は html と共通．
- handout (Tufte 形式): Quarto の余白のレイアウト (reference- / citation- / fig-cap-location: margin)．手本は Quarto のギャラリーの tufte．
  - LaTeX: A4 で本文 115mm・余白 52mm (geometry)．余白は sidenotes ＋ marginfix．
    - 余白の図 (marginfigure) と本文＋余白の図 (figure*) では，Quarto が \sidecaption を使うので見出しが余白の外に出て見えない
      → ~\AtBeginEnvironment{marginfigure|figure*}{\let\sidecaption\caption}~
    - ~.column-margin~ / ~.aside~ は \marginnote になり，余白の図や脚注と重なる → 本文の流れの中 (~\ifinner~ でない所) では \marginpar に替える
    - 表の見出しを余白にすると longtable の中に \sidecaption が入り止まる (Quarto 1.10) → tbl-cap-location: top
  - typst: Quarto 同梱の marginalia で組まれる．脚注を余白に出すと本文の下に区切り線だけ残るので ~#set footnote.entry(separator: none)~
  - 書誌を余白に出すと最後の参考文献の一覧は作られない
- 図の余白の切り詰め (crop) は既定で切る (2026-10-12)．
  - 症状: report-latex で "The magick package is required to crop \"…_files/figure-pdf/…png\" but not available."
  - 原因: Quarto (share/rmd/execute.R) は PDF の書き出しで装置が pdf のとき，pdfcrop と ghostscript があれば knitr の crop を有効にする
    (~opts_chunk$crop <- TRUE~ と crop の hook)．その後で yaml の ~dev: png~ が装置を上書きするので crop は残り，
    knitr は PNG の図の切り詰めに R の magick を使おうとする．magick が無いとメッセージだけ出て図はそのまま．
  - 対処: report-latex.yaml / handout-latex.yaml の ~knitr: opts_chunk:~ に ~crop: false~．出力は今までと同じで，機械によって変わらない．
    ggplot の外側の余白を詰めたい図だけ ~#+ATTR_QUARTO: :crop true~ (文書全体は R のチャンクで ~knitr::opts_chunk$set(crop = TRUE)~)．
    そのときは書き出す機械に magick を入れる (~install.packages("magick")~．CRAN の macOS 版は ImageMagick 込み)．
    typst 版は crop が有効にならないので関係しない．
  - どんな図に効くか: crop は図の外周の「背景と同じ色の帯」を削るだけ．ggplot の外側の余白 (~plot.margin~) は既定で 5.5pt と小さく，
    ふつうの ggplot ではほとんど変わらない (piml-review で確かめた)．はっきり効くのは，縦横比を固定した図
    (~coord_fixed()~ / ~coord_equal()~，地図，正方形の散布図: fig-width / fig-height の比と合わないと左右か上下に空白が残る)，
    余白の広い base graphics (~par(mar = …)~)，凡例や注記を外に置いて片側が空いた図．
  - ggplot の余白を思いどおりに詰めるなら crop より ~theme(plot.margin = margin(0, 0, 0, 0))~ が確実
    (crop は削れる量が図しだい)．crop は自動で削ってほしい図に．
- 番号付きの式は org の latex 環境では ~{#eq-…}~ を付けられないので，~#+begin_export markdown~ の中に ~$$ … $$ {#eq-…}~ と書く．
- サンプルは ~samples/org/report-sample.org~，~handout-sample.org~ (~make report~ / ~report-typst~ / ~handout~ / ~handout-typst~ / ~docs~)．
  Claude 側では TeX Live (texlive-lang-japanese ほか) と R を入れ，org → qmd → PDF / html まで通して確かめた．

* org で書くときの注意 (はまった所)
- 強調 ~*…*~ の直後が全角の句読点 (，．) だと効かない．段落の見出し語は「*語*: 」の形にするか，後ろに空白を入れる．
- org の表のセルの ~|~ は列の区切りになる．数式の絶対値は ~\lvert … \rvert~．
- 生の ~\begin{align}~ は html では動くが typst では落ちる．~\[\begin{aligned} … \end{aligned}\]~ と 1 行目と最終行を \[ \] にくっつけて書く (\begin が行頭だと org が latex 環境とみなす)．
- 数式の和の位置を揃えるなら alignat (html のみ) か aligned で ~&\sum~ の前で揃える．
- R チャンクのオプションで ~"…\(x\)…"~ のように二重引用符にバックスラッシュを入れると YAML のエラー．単引用符を使う．
- ~#+begin_callout~ の ~:title~ の中に引用 ~[cite:…]~ は書けない (文字列属性)．本文の 1 行目に書く．
- 特殊ブロックの ~:title~ (2026-10-08): ox-quarto 本体はどのブロックでも ~:title~ を div の中の ~## 見出し~ にし，属性から外していた．
  iframe の title (アクセシビリティ用) が届かず，div の中に余計な見出しが入っていた．ox-quarto-ext-block.el で特殊ブロックのトランスコーダを差し替え，
  callout (~callout~ / ~callout-*~) だけ見出し，それ以外は属性 ~title="…"~ にした．属性の値の ~\~ と ~"~ はエスケープする (iframe.lua も html に書くときにエスケープ)．
  本体 (submodule) は書き換えない．samples の qmd は変更の前後で同じ．
- 下付き文字の誤変換を避けるため ~#+OPTIONS: ^:{}~．
- 先頭 (最初の見出しの前．~Preamble :ignore:~ の中など) に置く ~#+begin_export latex~ は，revealjs では空白のスライドを作る．
  ~#+begin_content-visible :when-format "pdf"~ で囲んで PDF だけに出す (samples/org/slide-sample.org)．
- 空の列を入れ子にすると ox-quarto の書き出しが止まることがあった (timeout を付けて実行)．
- 使わなくなったスライドは削除せず見出しに ~COMMENT~ (文書としては残す)．
