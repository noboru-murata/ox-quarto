** 文字と数式の大きさ: text-size.scss
- ~.text-NN~ (div / span / スライド全体．見出しは変えない)，~.math-NN~，~.math-scroll~．NN は 50〜150 を 5 刻み，160〜200 を 10 刻み．

** 梗概と節扉: section-toc
- ~lib/section-toc.lua~ が第 1 階層の見出しから一覧を作る．~{.overview}~ の見出しは各節の題と ~summary~ を並べた梗概，各節の見出しは現在の節を強調した一覧 (節扉)．
- 梗概・節扉は見出しを隠す (~.notitle~．見出しは DOM に残るのでメニューには出る)．~{.show-title}~ で表示．
- 節扉の背景は ~--oer-section-bg~ (既定は表紙の暗色を 6% 明るく．~$section-slide-bg-lighten~)．表紙が暗くない palette では地色のまま．~{.light}~ で地色．
  reveal は背景の計算後の色から has-dark-background を付けるので，暗い節扉の文字色は自動で切り替わる．
- talk-*.yaml だけが使う．lecture.yaml は section-toc.lua / section-toc.scss を入れず，節扉は見出しの題をそのまま出す (~{.overview}~ の一覧も作られない)．

** iframe (lib/iframe.lua，scss/iframe.scss)
- ~#+begin_iframe :src "x.html"~ は既定で高さ 500px だが，図と同じ ~$fig-max-height~ で頭打ち (約 460px)．
- 2026-10-08 に追加: ~:height~ を明示したらその高さ (頭打ちなし)，~:fill "tall"~ は ~$fig-full-height~ (35ex)，
  ~:fill "canvas"~ はキャンバス 1050×700 全体を覆う (見出しは visibility: hidden．スライドの top を 0 にするため ~:has(.iframe-canvas)~ と !important)．
  中のページは 1050×700 の窓として描かれ，スライドと一緒に拡大縮小される．操作もできる (iframe をクリックするとキー入力はそちらへ)．
- reveal の ~{background-iframe="…"}~ は窓全体に敷く背景で，余白の帯まで覆い，操作には background-interactive が要る．
  背景の色を ~background-color~ でも渡すと reveal が暗い背景と判断して文字を明るくする (iframe の色は reveal には分からない)．
- 例は ~samples/org/iframe-sample.org~ (取り込む html は ~samples/org/iframe/~．外部の読み込みなし)．
  書き出した html から相対パスで読むので，~make iframe~ は ~org/iframe/~ を ~html/iframe/~ に写す．
  embed-resources でも iframe と background-iframe の src は埋め込まれない (相対パスのまま)．

** 図
- コードチャンクの図は高さ ~$fig-max-height~ (26.5ex) に固定し，幅は縦横比で決まる (~$fig-max-height~)．横長すぎる図は幅で縮み上下が空く → fig-width/fig-height の比を 2〜2.5 程度に．
- ポンチ絵は ggplot より SVG を直接書く方がよい (線と文字がくっきり，修正が容易)．~figs/*.svg~ を ~#+attr_quarto: :width "100%"~ ~[[file:figs/x.svg]]~ で入れる．
  embed-resources で html に埋め込まれ，PDF では Quarto が rsvg-convert で変換する．
- mermaid は ~#+begin_src mermaid~ (ox-quarto-ext の実行言語)．

* 文献
- 文献ファイルはプロジェクトごとに 1 つ (例: ~talk/piml.bib~)．全体の Zotero 書き出し (~notes/library.bib~) から使う分だけ抜き出し，abstract / file / keywords / urldate を除く．足りない文献はプロジェクトの bib に追記し，後で Zotero に登録する．
- ~library.bib~ のキーに ~<~ ~>~ があると pandoc が読めない．漢字のキーも避ける．
- 書式は ~_quarto/csl/apa.csl~ (本文は (著者, 年))．org では ~[cite:@key]~ / ~[cite/t:@key]~．
- ~lib/cite-aside.lua~: スライドごとに引用した文献の書誌をそのスライドの脚注欄に出す．
  - 書誌全体を doi / url へのリンクにし (新しいタブ)，doi の文字列は出さない．
  - ~cite-aside-max~ (talk / lecture は 2) より多く引用したスライドでは出さない．~{.no-cite-aside}~ / ~{.cite-aside}~．
  - 発表者ノートの中の引用は数えない (ノートの div そのものも除外する必要があった)．
  - 相互参照 (~@fig-x~ ~@tbl-x~ など) は citeproc に渡さない (渡すと "citation not found" の警告が出る)．
- 参考文献のスライドは ~::: {#refs}~．Quarto の script が #refs を小さなスクロール枠にするので CSS で打ち消し，スライドを ~{.scrollable}~ にした．
- report (typst) では csl のパスの ~_~ を typst が扱えない (~\_quarto~ になる) ので ~bibliographystyle: apa~ (typst 内蔵) を使う．
- 文献の表記を英語 (et al.) にするため report では ~lang~ を設定せず，~language:~ で見出し語だけ日本語にした．~lang: ja~ だと「ほか」「2020年」になる．

* 解説文 (report)
- 2026-10-08: ~report-typst~ (旧 report．~report.{org,yaml}~ はそこへのリンク)，~report-latex~ (PDF を lualatex で)，~report-tufte~ (Tufte 形式) を置いた．
- report-typst: typst は文献の一覧を最後に自分の見出し ("Bibliography") 付きで出すので，~#set bibliography(title: none)~ で消し，org の「参考文献」の見出しを使う．
- report-latex: documentclass scrartcl，日本語は luatexja-preset．LaTeX は csl のパスの ~_~ を扱えるので csl は html と共通．
- report-tufte: Quarto の余白のレイアウト (reference- / citation- / fig-cap-location: margin)．A4 で本文 115mm・余白 52mm (geometry)．
  - 表の見出しを余白にすると longtable の中に \sidecaption が入り LaTeX が止まる (Quarto 1.10) → tbl-cap-location: top
  - ~column: page-right~ の図に見出しを付けると，見出しが余白側に置かれて見えなくなる → 見出しなし
  - 書誌を余白に出すと最後の参考文献の一覧は作られない．~[…]{.aside}~ は marginnote になり sidenote と重なることがある
- 番号付きの式は org の latex 環境では ~{#eq-…}~ を付けられないので，~#+begin_export markdown~ の中に ~$$ … $$ {#eq-…}~ と書く．
- サンプルは ~samples/org/report-sample.org~，~tufte-sample.org~ (~make report~ / ~report-typst~ / ~tufte~ / ~docs~)．
  Claude 側では TeX Live (texlive-lang-japanese ほか) と R を入れ，org → qmd → PDF / html まで通して確かめた．

* org で書くときの注意 (はまった所)
- 強調 ~*…*~ の直後が全角の句読点 (，．) だと効かない．段落の見出し語は「*語*: 」の形にするか，後ろに空白を入れる．
- org の表のセルの ~|~ は列の区切りになる．数式の絶対値は ~\lvert … \rvert~．
- 生の ~\begin{align}~ は html では動くが typst では落ちる．~\[\begin{aligned} … \end{aligned}\]~ と 1 行目と最終行を \[ \] にくっつけて書く (\begin が行頭だと org が latex 環境とみなす)．
- 数式の和の位置を揃えるなら alignat (html のみ) か aligned で ~&\sum~ の前で揃える．
- R チャンクのオプションで ~"…\(x\)…"~ のように二重引用符にバックスラッシュを入れると YAML のエラー．単引用符を使う．
- ~#+begin_callout~ の ~:title~ の中に引用 ~[cite:…]~ は書けない (文字列属性)．本文の 1 行目に書く．
- 下付き文字の誤変換を避けるため ~#+OPTIONS: ^:{}~．
- 先頭 (最初の見出しの前．~Preamble :ignore:~ の中など) に置く ~#+begin_export latex~ は，revealjs では空白のスライドを作る．
  ~#+begin_content-visible :when-format "pdf"~ で囲んで PDF だけに出す (samples/org/slide-sample.org)．
- 空の列を入れ子にすると ox-quarto の書き出しが止まることがあった (timeout を付けて実行)．
- 使わなくなったスライドは削除せず見出しに ~COMMENT~ (文書としては残す)．

* 講演の作り方の約束 (PIML の講演で決めたこと)
- 一般向けの講演: 例題番号への言及を前半に出さない．専門用語は括弧に小さく添える．
- 最初の節は導入 (何か・何を目指すか・何が要るか・壁・PIML の役割)，次の節で概念・要素技術・研究の流れ．

- 例題は「問題 → 定式化 (統一の表: 学習器・学習する量・方程式 L_r・境界 L_b・データ L_d・損失) → 結果 → 意味の一行」．表は ~{.formulation}~．
- 発表者ノートは解説文を書ける程度に詳しく．解説文 (report) はノートから再構成した．

- 改名・移動は端末側で ~mv -n~．削除は許可を得てから．
- git は Claude が commit までを行い，push はユーザーが手動で行う (Claude の端末からは GitHub に SSH で接続できない)．
