#+TITLE: ox-quarto — Org で書き，Quarto で仕上げるための部品一式
#+STARTUP: content indent

Org で書いたスライド・講義資料・解説文を，[[https://github.com/jrgant/ox-quarto][ox-quarto]] で qmd に書き出し，
[[https://quarto.org][Quarto]] で revealjs / html / PDF (LaTeX・typst) に仕上げるための
Emacs Lisp・テーマ (SCSS)・front matter (YAML)・Lua フィルタ・SETUPFILE・サンプルをまとめたもの．

このリポジトリの名前も ox-quarto だが，Org の書き出し器 (exporter) そのものは
Jason Gantenberg 氏の [[https://github.com/jrgant/ox-quarto][jrgant/ox-quarto]] で，ここでは submodule (~lisp/ox-quarto~) として持つ．
以下，区別が要るときは書き出し器を「ox-quarto 本体」と呼ぶ．

* 動機
- 原稿は Org で書きたい．見出しの折りたたみ，babel，~[cite:@key]~ の引用，発表者ノートや ~COMMENT~ による頁の出し入れが，
  そのまま講義や講演の準備の道具になる．
- 仕上げは Quarto に任せたい．1 つの原稿から revealjs のスライド・html の解説・PDF を作れ，
  R のチャンクの実行 (knitr)，citeproc による文献，callout や列 (columns)，Lua フィルタが使える．
- ox-quarto 本体はこの橋渡しをするが，Org 側の包み方は最小限である (本体の README にもそう書かれている)．
  見出しの属性，チャンクのオプション，図の記法，~#+begin_export latex~ などは素のままでは Quarto に届かず，
  スライドの見た目も Quarto の既定のままになる．
- そこで，書き出しを補う Emacs Lisp (ox-quarto-ext) と，講義・講演・解説文のための見た目と設定を，
  プロジェクトをまたいで使い回せる形でここにまとめた．

* 由来
- 書き出し器: [[https://github.com/jrgant/ox-quarto][jrgant/ox-quarto]] (Jason Gantenberg．ox-md をもとにした Org の Quarto バックエンド，GPL-3.0)．
  submodule として版を固定して使う．
- スライドの構造の層 ~oerreveal.scss~: Emacs のパッケージ [[https://gitlab.com/oer/oer-reveal][oer-reveal]]
  (Jens Lechtenbörger．org-re-reveal を拡張して reveal.js の教材を作るもの．emacs-reveal の一部) の
  標準のテーマ ~css/oer-reveal.css~ をもとに，Quarto の SCSS テーマに移したもの．名前 oerreveal はここから．
- revealjs のポインタ: Quarto 公式の拡張 [[https://github.com/quarto-ext/pointer][quarto-ext/pointer]] (Posit)．
- 講演や講義の資料を作成する中で整え，2026-10 に独立したリポジトリにした．
  経緯と設計の判断は [[file:NOTES.org][NOTES.org]] にある．

* 特徴
- *書き出しの補い (ox-quarto-ext)*: 見出しの属性 ~:QUARTO_ATTR:~ と ~:notitle:~，~#+ATTR_QUARTO:~ からチャンクのオプション (~#|~)，
  実行するチャンクと表示だけのブロックの振り分け，画像を Quarto の図 (~#fig-~ で相互参照) に，~#+begin_export latex~ を raw block に．
  ox-md の関数には advice を足さず，quarto バックエンドのトランスコーダとして入れる．
- *テーマ*: 構造 (oerreveal)・配色 (jade / indigo / lavender / burgundy / dracula)・修飾 (deck) の 3 層．
  配色や修飾は 1 行の入れ替えで変わる．
- *講演の部品*: 梗概と節扉の一覧 (section-toc)，スライドごとの引用の書誌を脚注欄に (cite-aside)，表紙の QR コード (title-qr)，
  文字・数式の大きさ (~.text-NN~ / ~.math-NN~)，大きな数値 (kpi)，列の間の矢印，定式化の表．
- *front matter の一式*: 講演 (talk-*)・講義 (lecture)・解説文 (report) を SETUPFILE の 1 行で選ぶ．
- *コマンド行の書き出し*: ~tools/export-batch.el~ (org → qmd) と，サンプル用の ~samples/Makefile~．

* 必要なもの
- Emacs (31.1 で確認)，Org 10.0-pre 以降，org-contrib の ox-extra (~:ignore:~ タグ)
- Quarto (1.10.18 で確認．pandoc と typst は同梱)
- R と knitr (R のチャンクを使うとき)
- LuaLaTeX と luatexja (講義の PDF を LaTeX で作るとき)

* インストール
** 取得
ox-quarto 本体を submodule として持つので，clone では submodule も取る．
#+begin_src sh
  git clone --recurse-submodules https://github.com/noboru-murata/ox-quarto.git /path/to/ox-quarto
  # clone 済みなら
  git submodule update --init
#+end_src
以下，~/path/to/ox-quarto~ は clone した場所に読み替える．

** Emacs の設定
本体 (~lisp/ox-quarto~) と拡張 (~lisp/ox-quarto-ext~) をこのリポジトリから読む．
package.el や straight などで ox-quarto を別に取らない (版が 2 つになり，どちらが読まれるか分かりにくくなる)．

use-package の場合:
#+begin_src emacs-lisp
  (use-package ox-quarto
    :ensure nil                 ; package.el から取らない (straight なら :straight nil)
    :load-path "/path/to/ox-quarto/lisp/ox-quarto"
    :after ox)

  (use-package ox-quarto-ext
    :ensure nil
    :load-path "/path/to/ox-quarto/lisp/ox-quarto-ext"
    :after ox-quarto
    :config
    (ox-quarto-ext-install-org-settings))
#+end_src

leaf の場合:
#+begin_src emacs-lisp
  (leaf ox-quarto
    :straight nil               ; straight から取らない (package.el なら :ensure nil)
    :load-path ("/path/to/ox-quarto/lisp/ox-quarto"
                "/path/to/ox-quarto/lisp/ox-quarto-ext")
    :after ox
    :require ox-quarto ox-quarto-ext
    :config
    (ox-quarto-ext-install-org-settings))
#+end_src

どちらも使わない場合:
#+begin_src emacs-lisp
  (add-to-list 'load-path "/path/to/ox-quarto/lisp/ox-quarto")
  (add-to-list 'load-path "/path/to/ox-quarto/lisp/ox-quarto-ext")
  (with-eval-after-load 'ox
    (require 'ox-quarto)
    (require 'ox-quarto-ext)
    (ox-quarto-ext-install-org-settings))
#+end_src
読まれている場所は ~(locate-library "ox-quarto")~ と ~(locate-library "ox-quarto-ext")~ で確かめる．
ox-quarto-ext の機能と変数は [[file:lisp/ox-quarto-ext/README.md][lisp/ox-quarto-ext/README.md]]．

** 更新
#+begin_src sh
  git pull && git submodule update --init          # このリポジトリ
  git submodule update --remote lisp/ox-quarto     # ox-quarto 本体を上流 (main) に上げる
#+end_src
ox-quarto-ext は本体の内部関数に依存するので，本体を上げたらサンプルを書き出して確かめてから commit する．

* 使い方
** 1. プロジェクトの準備
org を置くフォルダに，~_quarto~ と ~_extensions~ のシンボリックリンクを作る．
相対パスでリンクしておくと，両方を一緒に動かしてもリンクが切れない (例: ~ln -s ../ox-quarto/_quarto _quarto~)．
#+begin_src sh
  cd /path/to/my-talk           # org を置くフォルダ
  ln -s /path/to/ox-quarto/_quarto      _quarto
  ln -s /path/to/ox-quarto/_extensions  _extensions
#+end_src

** 2. SETUPFILE を選ぶ
org の先頭で SETUPFILE を 1 行書く．これが Quarto の front matter (テーマ・フィルタ・形式) を決める．
講演と講義は，配色と修飾 (deck) を続く行で選ぶ (書かなければ既定)．
#+begin_src org
  ,#+TITLE: 講演の題
  ,#+AUTHOR: 名前
  :QUARTO:
  ,#+SETUPFILE: _quarto/org/talk.org
  ,#+QUARTO_PALETTE: lavender
  ,#+QUARTO_DECK: pin
  ,#+BIBLIOGRAPHY: refs.bib
  :END:
#+end_src

| SETUPFILE                             | 用途                 | 内容                                                                       |
|---------------------------------------+----------------------+----------------------------------------------------------------------------|
| _quarto/org/talk.org                  | 講演                 | revealjs のみ．oerreveal＋palette (既定 jade)＋lecture/line-deck＋parts＋全機能 |
| _quarto/org/lecture.org               | 講義                 | revealjs＋pdf (lualatex)＋html．palette (既定 indigo)．title-bg．節扉は見出しをそのまま出す (section-toc なし) |
| _quarto/org/report-latex.org          | 解説文・報告書       | html (目次・余白の引用) と LaTeX (lualatex，日本語は luatexja-preset) の PDF．文献は APA |
| _quarto/org/report-typst.org          | 解説文・報告書       | 同上で PDF を typst で                                                    |
| _quarto/org/handout-latex.org         | 解説文 (Tufte 形式)  | 右の余白を広く取り，脚注・引用の書誌・図の見出し・小さな図を余白に．LaTeX の PDF と html |
| _quarto/org/handout-typst.org         | 解説文 (Tufte 形式)  | 同上で PDF を typst で (Quarto 同梱の marginalia)                          |
| _quarto/org/default.org / dracula.org | 見出し装飾テーマの例 | Quarto 標準テーマ＋default/dracula-header                                 |

| 行                    | 値                                                       | 働き                                                       |
|-----------------------+----------------------------------------------------------+------------------------------------------------------------|
| ~#+QUARTO_PALETTE:~   | jade / indigo / lavender / burgundy / dracula            | theme の ~*-palette.scss~ と ~callout-palette:~ (PDF / html の callout の色) を差し替える．dracula はコードも dracula 配色，講義では表紙の title-bg を外す．report / handout では callout の色だけ |
| ~#+QUARTO_DECK:~      | logo / pin / paw / dot / size-80 / size-90 / size-110 (空白で区切って並べる) | ~<名前>-deck.scss~ を theme の最後の deck の後に足す．logo: 見出しの左にロゴ・題は右寄せ，pin: 見出しを上に固定，paw: pointer (~q~ で出し入れ) を肉球の形に (lecture は既定で paw)，dot: pointer を丸い点に戻す，size-N: スライド全体の文字を基準 (講義・講演それぞれ) の N% に (図とスクロールの箱の高さは変えない．LaTeX の 10pt / 12pt のような切り替え)．~_quarto/scss~ に無い名前は ~_quarto/local/<名前>-deck.scss~ (手元の deck．自分の絵の pointer など) |

講演 (~talk.yaml~) は講義の構造 (~oerreveal.scss~) の上に講演用の上書き ~talk-base.scss~ を重ねる．文字の基準をやや小さく (30.4px．講義は 32px)，
箇条書きの目印を主色で描き (1 段目 四角，2 段目 横棒，3 段目 丸．下の階層は小さく淡く)，callout を枠線の無い淡いカードに，
書体を本文ヒラギノ角ゴ (無ければ BIZ UDP ゴシック)・見出しヒラギノ丸ゴにしている (無い機械では角ゴ．~_quarto/scss/talk-base.scss~ の先頭)．

yaml は講演と講義で 1 つずつ (~talk.yaml~ / ~lecture.yaml~)．書き出すときに ox-quarto-ext が theme の行を書き換える
(yaml のファイルは変えない．何を書き換えたかは qmd の front matter の先頭のコメントに出る．lisp/ox-quarto-ext/README.md)．
前からの ~talk-<配色>.org~ (と ~talk-logo.org~)，~lecture-<配色>.org~ も使える (talk.org / lecture.org に上の行を足しただけのもの)．
~report.org~ は ~report-latex.org~ へ，~handout.org~ は ~handout-latex.org~ へのシンボリックリンク (yaml も同じ)．

** 3. 書き出す
- Emacs から: ~C-c C-e~ → Quarto で qmd に書き出す．
- コマンド行から:
  #+begin_src sh
    emacs --batch -Q -l /path/to/ox-quarto/tools/export-batch.el talk.org
    quarto render talk.qmd --to revealjs        # 講義は pdf / html も，解説文は html / typst
  #+end_src
  ~export-batch.el~ は org と org-contrib を straight の build (~~/.emacs.d/straight/build/~) から探す．
  違う場所なら環境変数 ~OXQ_ORG_DIR~ / ~OXQ_ORG_CONTRIB_DIR~ で指定する．
- 配布用の PDF: ~python3 /path/to/ox-quarto/tools/oxq-pdf.py talk.qmd~．front matter の ~notes-pdf~ で方式を選ぶ．
  - ~slides~ (講演の既定): スライドの画像と発表者ノートを A4 縦に並べる (~tools/notes-handout.py~．uv と Chromium が要る: ~brew install uv~，一度だけ ~uv run --with playwright playwright install chromium~．playwright は uv が用意するので pip は使わない)．
  - ~document~ (講義・解説文の既定): Quarto の pdf 形式．発表者ノートは ~slide-notes~ (既定は講義が枠，Tufte 形式が余白．org で ~#+QUARTO_OPTIONS: slide-notes:margin~ のように変える) に従う．
  - org から変えるとき: ~#+QUARTO_OPTIONS: notes-pdf:slides notes-pdf-layout:side notes-pdf-engine:lualatex~
    (layout: stack / side，engine: typst / lualatex / xelatex，ほかに notes-pdf-class: jlreq / bxjsarticle，notes-pdf-keep:true で tex を残す)
    side の左右の幅は ~notes-pdf-ratio:60:40~ (スライド:ノートの比．既定 60:40．~55:45~ や ~65:35~ (1 頁に 3 枚並ぶ上限) など)．
  - ノートの詳しい部分: ノートの中の ~#+begin_detail~ … ~#+end_detail~ (行の中なら ~[…]{.detail}~) は発表者画面には出るが，
    ノート付きの PDF には載せない (欄が狭いので要点だけに)．載せるときは ~#+QUARTO_OPTIONS: notes-pdf-detail:t~ (~--notes-detail~)．
  - ノートなしの配布用 PDF (公開用．~--no-notes~，講演の Makefile では ~make slide-handout~ (前の名前 ~talk-handout~ も同じ)): スライドだけを 1 頁に 6 枚 (3 段 × 2 列)．
    org から格子を変えるとき: ~#+QUARTO_OPTIONS: handout-grid:4x2~ (段x列．1 頁 8 枚)．ノート付きの ~notes-pdf-*~ とは別のキーで，互いに効かない．
    1 枚の幅は列の数で決まり，段が頁に収まらなければ縮める．コマンド行の ~--grid~ / ~--per-page~ (publish.mk の ~PUB_HANDOUT_OPTS~) が優先．
- 決まった手順を繰り返すなら Makefile にまとめる (例: [[file:samples/Makefile][samples/Makefile]])．

** よく使う書き方 (org)
| したいこと                   | org での書き方                                                                                       |
|------------------------------+------------------------------------------------------------------------------------------------------|
| 梗概スライド                 | ~* 講演の流れ~ に ~:QUARTO_ATTR: {.overview}~                                                        |
| 節扉の説明 (梗概に出る)      | ~* 節~ に ~:QUARTO_ATTR: {summary="…"}~                                                              |
| 節扉を地色のまま／一覧なし   | ~{.light}~ ／ ~{.no-toc}~ (一覧から外す: ~{.toc-skip}~)                                              |
| 文字・数式の大きさ           | ~#+begin_text-85~ … ／ ~#+begin_math-80~ … ／ 見出しに ~{.text-90}~                                  |
| callout の大きさ             | ~#+begin_callout-note :title "定義" :class "text-85"~                                                |
| callout のアイコンと帯       | ~:title~ を付けた callout は自動でアイコンなし (どの形式でも)．残すなら ~:icon true~．題の無い ~callout-*~ は自動で minimal (帯もアイコンもなく，種類の色の線と地だけ)．Quarto の既定 (帯に「ノート」などとアイコン) にするなら ~:icon true~．例は ~samples/org/report-sample.org~ |
| 特殊ブロックの ~:title~      | callout では見出し (~## …~)，それ以外 (~#+begin_iframe~ など) では属性 ~title="…"~                     |
| 大きな数値                   | ~#+begin_kpi :class "alert"~ ~[0.7 ms]{.kpi-value}~ ~[説明]{.kpi-label}~                               |
| 列の間の矢印                 | 列に ~#+attr_quarto: :width "4%" :class "flow-arrow"~                                                |
| 1 列目の狭い表               | 見出しに ~:QUARTO_ATTR: {.formulation}~                                                              |
| 図だけのスライド             | 見出しに ~:notitle:~ タグ，大きな図は ~{.fig-tall}~                                                  |
| 形式ごとの指定               | ~#+QUARTO_REVEALJS_OPTIONS: csl:my.csl slide-number:false~ (~#+QUARTO_HTML_OPTIONS~ なども)．yaml の ~format:~ のその形式の中に書き込まれ，同じキーは置き換わる (ox-quarto-ext-format.el) |
| 番号つきの式                 | latex 環境に ~#+NAME: eq-…~ (環境の中の ~\label{eq-…}~ でも)，参照は ~@eq-…~．番号は名前を付けた式だけに付く (html も PDF も．PDF は showonlyrefs と ~\noeqref~)．align は aligned にして ~$$ … $$ {#eq-…}~ に書き出す (番号はかたまり 1 つに 1 つ．ox-quarto-ext-math.el) |
| 例・定理                     | ~#+ATTR_QUARTO: :id exm-…~ を付けた ~#+begin_exm~ (~#+begin_example~ は使えない)．定理は ~thm-~ ・補題 ~lem-~ ・系 ~cor-~ ・定義 ~def-~ |
| 行内数式の直後の数字         | ~\(x\)2~ はそのまま書いてよい (書き出しで ~$x$<!---->2~ にする) |
| コードの行数 (スライド)       | 12 行を超えるとスクロール．ブロックごとに変えるときは，実行するチャンクは ~#+ATTR_QUARTO: :class-source code-lines-8~ (チャンクオプションの class-source になる)，表示だけのブロック (~:exec no~ や yaml など) は ~#+ATTR_QUARTO: :class code-lines-8~ (~{.python .code-lines-8}~ になる)．上限なしは ~code-lines-none~ |
| PDF の用紙                   | 講義・解説文・配布物の yaml の既定は A4 (~papersize: a4~)．変えるときは ~#+QUARTO_PDF_OPTIONS: papersize:letter~ |
| 表紙の所属                   | ~#+INSTITUTE: ○○大学 △△学部~ (beamer と同じ．氏名の下に出る．複数なら行を重ねる)               |
| 図の余白を詰める (PDF)       | チャンクに ~#+ATTR_QUARTO: :crop true~ (文書全体は R のチャンクで ~knitr::opts_chunk$set(crop = TRUE)~)．既定は詰めない (report-latex / handout-latex の ~crop: false~)．PNG の図には R の magick が要る．削るのは背景と同じ色の外周だけなので，効くのは縦横比を固定した図 (~coord_fixed()~，地図) や余白の広い base graphics．ggplot の余白は ~theme(plot.margin = margin(0, 0, 0, 0))~ の方が確実 (NOTES.org) |
| 表紙の題の高さ               | 題の上端は上から ~$title-slide-top~ (既定 202px) に固定．副題・氏名・所属は下に積むので，行が増えても題は動かない．~null~ で従来の中央寄せ (oerreveal.scss) |
| 表紙の QR コード             | ~#+QUARTO_QR: figs/qr-edition.svg~ と ~#+QUARTO_QR_CAPTION: https://…/talks/<主題>/<版>/~ (表紙の右下に QR と小さな URL．CAPTION は省略可)．画像は ~uv run --script tools/oxq-qr.py URL figs/qr-edition.svg~．位置と大きさは parts.scss の ~$title-qr-*~ (revealjs のみ) |
| 頁の端に固定 (QR コードなど) | ~#+begin_export markdown~ ~::: {.absolute .pin-top right=0 pin-top="0"}~ ~![](figs/qr-edition.svg){.qr-tile}~ ~:::~ ~#+end_export~．中央寄せの頁でもキャンバスの上端から 0px に止まる (下端は ~.pin-bottom~ と ~pin-bottom="40"~．_quarto/lib/pin.lua)．~.qr-tile~ は白い地 (暗い頁でも読める)．Quarto の ~.absolute~ の ~top~ / ~bottom~ だけでは中身の端からの位置になり，中身の量で動く．例は talk-sample の「資料の公開」 |
| 頁の下の URL                 | ~#+begin_export markdown~ ~::: footer~ ~[URL](URL)~ ~:::~ ~#+end_export~ (Quarto の頁ごとの footer．暗い頁では明るい色) |
| 中央寄せ                     | ~#+begin_center~ … ~#+end_center~ → ~::: {.text-center}~ (ox-quarto-ext)．中の脚注・強調もそのまま効き，PDF (LaTeX の center，typst の align) にも出る (_quarto/lib/text-center.lua) |
| 謝辞の頁                     | 部品のファイル ([[file:samples/org/acknowledgements.org][acknowledgements.org]]) を ~#+INCLUDE: "acknowledgements.org" :minlevel 2~ で読み込む．出さないときはその行をコメントに．~#+begin_people~ (~- [[file:写真]] 名前 :: 所属~)，~#+begin_funding~，~#+begin_logos~，~#+begin_ack-note~ |
| 図をキャンバス全体に         | 見出しに ~:QUARTO_ATTR: {.fill-canvas}~．画像・~#+begin_export html~ の <svg>・図が 1050×700 いっぱいになり，見出しは隠れる (題は図の中に描く)．見出しの下いっぱいなら ~{.fig-tall}~ |
| 図と表を横に並べる (解説文)  | ~#+begin_figpanel :id fig-x :layout "[[55,45]]" :layout-valign "center"~ の中に，図のチャンク (~#\| label: fig-x-a~ と ~#\| fig-cap: …~) と ~#+begin_subfig :id fig-x-b~ (表のチャンクと説明の一行) ~#+end_subfig~ を置き，最後に全体の説明の一行で ~#+end_figpanel~．~[[55,45]]~ は列の幅の比．本文では ~@fig-x~ / ~@fig-x-b~ |
| 小さな部品                   | ~[(問題3)]{.ex}~ 行の中の小さな灰色の参照，~[説明]{.cap}~ コードや図の下の小さな行，~#+begin_tbl-key~ … ~#+end_tbl-key~ で表の第 1 列を折り返さない (parts.scss) |
| 頁のまとめの一文             | 題なしの ~#+begin_callout-caution~ (自動で minimal)．下の「callout の役割」 |
| 横長の図を低く               | ~#+begin_fig-short~ … ~#+end_fig-short~ (~<fs~) か見出しに ~{.fig-short}~．fig-width / fig-height が約 3.4 以上の図に (16ex で幅が本文の幅にほぼ一致) |
| html を取り込む              | ~#+begin_iframe :src "demo.html"~ (~:height "560px"~ / ~:fill "tall"~ / キャンバス全体は ~:fill "canvas"~)．例は ~samples/org/iframe-sample.org~．配布用の PDF では iframe の代わりに title・ブロックの中身・ファイル名の札が出る．~:poster "figs/demo-thumb.png"~ なら札にその画像 (~tools/oxq-thumb.py~ で iframe の src を開いて撮れる) |
| 引用                         | ~[cite:@key]~ → (著者, 年)，~[cite/t:@key]~ → 著者 (年)．文献一覧はスライドでは 4 名以上を 2 名 + et al. (apa-short.csl)，解説文は APA どおり (apa.csl) |
| 引用の書誌を脚注欄に出さない | 見出しに ~{.no-cite-aside}~ (上限を超えても出す: ~{.cite-aside}~)                                    |
| 参考文献のスライド           | ~#+begin_export markdown~ ~::: {#refs}~ ~:::~ ~#+end_export~，見出しに ~{.scrollable .no-cite-aside}~ |
| 使わなくなったスライド       | 削除せず見出しに ~COMMENT~                                                                           |

Org で書くときにはまりやすい点 (全角の句読点の前の強調，表のセルの ~|~，数式の環境など) は
[[file:NOTES.org][NOTES.org]] の「org で書くときの注意」にまとめてある．

** callout の役割
callout は重大さではなく *発表の中の役割* で使い分ける (講演と講義に共通)．どの palette でも 5 つが別の色相になるようにしてある．

| 役割                        | 書き方                                  | 色 (jade の例) |
|-----------------------------+-----------------------------------------+----------------|
| 説明の箱                    | ~#+begin_callout-note :title "…"~       | 主色 (緑)      |
| 要 (定義・定式化・原則)     | ~#+begin_callout-important :title "…"~  | 赤             |
| 問題 (例題・練習問題)       | ~#+begin_callout-tip :title "問題 1"~   | 紫             |
| 注意・限界                  | ~#+begin_callout-warning :title "…"~    | 琥珀           |
| 頁の結論の一文              | ~#+begin_callout-caution~ (題なし)      | 青             |
| 範囲の外・参考              | ~#+begin_callout :title "…"~ (種類なし) | 灰             |

- tip と caution は Quarto の本来の意味 (助言・危険) とは違う使い方．tip は「問題」，caution は「頁の結論の一文」に当てる．
- 箱の中の太字はその箱の色になる (本文の強調の色ではない)．
- 色相の定位置は important = 赤，warning = 琥珀，caution = 青，tip = 紫，note = 主色．主色とぶつかる palette だけ代わりの色
  (indigo: caution は青緑，lavender: tip は緑，burgundy: important は紫)．dracula は主色が紫なので caution を明るい青にしてある．
- palette を足す・直すときは ~python3 tools/oxq-palette-check.py~ で，5 つの色相が 40° 以上離れていること，
  note 以外の 4 つが主色 (~$oer-primary~) から 35° 以上離れていること，地の上のコントラスト比が 4.5:1 以上であることを確かめる．
- 暗い頁 (~background-color~ が暗い頁) でも callout の中は明るい地の色の文字のままにしてある (印刷も同じ)．
- 講義・解説文・配布物の PDF (LaTeX) と html の callout も同じ役割の色にする (~_quarto/lib/callout-colors.lua~)．
  front matter の ~callout-palette:~ (lecture / report / handout の yaml の既定は indigo) の palette の色を使い，
  ~#+QUARTO_PALETTE:~ を書けばそれに替わる (report / handout でも書ける)．枠・見出しの帯・箱の中の太字がその色になる．
  暗い palette (dracula) は白い頁用の ~$doc-callout-color-*~ (同じ色相で暗め) を使う．html の印 (~:icon true~) も役割の色．typst の PDF (report-typst / handout-typst) も枠・印・題の帯・太字が役割の色
  (~_quarto/lib/callout-colors-typst.lua~ を yaml の filters で ~quarto~ の後に置く)．typst では題なしの callout も題の帯が出る (Quarto の typst は minimal を扱わない)．

** 文献 (引用している文献だけを抜き出す)
文献の正本 (Zotero / Better BibTeX が書き出す library.bib など．読むだけ) から，org で引用している文献だけを抜き出して文書の bib を作る．
正本の写しを文書のフォルダに置かずに済み，bib は引用に合わせていつも作り直せる．
#+begin_src makefile
  OXQ     ?= ../../../ox-quarto
  LIBRARY ?= $(OXQ)/../biblio/bib/library.bib     # 文献の正本 (既定もこの場所．OXQ_BIB_LIBRARY でも指定できる)

  bib: refs.bib
  refs.bib: slide.org companion.org $(LIBRARY) $(OXQ)/tools/oxq-bib.py
  	python3 $(OXQ)/tools/oxq-bib.py slide.org companion.org --library $(LIBRARY) -o $@
#+end_src
- 引用は org の ~[cite:@key]~ / ~[cite/t:@key]~ などから拾う (改行をまたいでもよい)．~#~ のコメント行，~~code~~ と ~=verbatim=~ の中，
  src / example / comment ブロックの中は除くので，書式の例を書いても拾わない．読む org は並べて渡す．
- abstract / file / keywords / urldate などの欄は除く (~--drop~ で変えられる)．引用の初出順に並べる．
- 正本に無いキーは今の bib から引き継いで知らせる．どこにも無ければ警告して終了コード 1．~-n~ は書き込まずに増減だけ表示．
- 正本に登録する前の文献は，書誌を手で書いた bib (例 ~research/pending.bib~) を ~--extra~ で渡す (複数可)．探す順は 正本 → ~--extra~ → 今の bib．
  ~--extra~ から写した文献は「登録待ち」と表示し，同じキーが正本に入ったら「正本に登録済み (消してよい)」と知らせる (正本の方を使う)．
- 中身が変わらなければ書かない (make が無駄に作り直さない)．文献の書式は csl (~_quarto/csl/~)．

** LaTeX の原稿の数式 (自作マクロと MathJax)
LaTeX で書いた原稿を org に移して html (MathJax) でも出すときの道具．html の数式は MathJax が読むので，
自作のマクロ (~\newcommand~，~\DeclarePairedDelimiter~ など) は素の TeX に展開しておき，MathJax で読めない式が無いか確かめる．
#+begin_src sh
  python3 tools/oxq-tex-macros.py --init preamble.tex > macros.json     # プリアンブルから定義の雛形 (直してから使う)
  python3 tools/oxq-tex-macros.py book.org -m macros.json -o book-x.org  # マクロを展開して書き出す (コメント行は触らない)
  python3 tools/oxq-tex-macros.py book.org -m macros.json --report       # 展開後に MathJax で動かない・要確認の命令の一覧
  (cd tools/oxq-mathjax-check && npm install)                            # 一度だけ (mathjax-full 3.2.2．node が要る)
  python3 tools/oxq-mathjax-check.py book-x.org                          # 全数式を MathJax で読む．誤りがあれば終了コード 1
#+end_src
- 定義の書き方 (~sym~ ~cmd~ ~paired~ ~stat~ ~optsub~ ~bigo~ の種類) は ~oxq-tex-macros.py~ の先頭．例は ~oxq-tex-macros.example.json~ (統計でよく使う 23 個)．
- 検査は Quarto の html と同じ程度の範囲 (全拡張＋mathtools，bussproofs なし) で読む．MathJax の既定では未定義の命令が
  赤字になるだけで誤りにならないので，検査では noundefined と noerrors を外して誤りとして数える．
- 番号つきの式・例・行内数式の直後の数字は ox-quarto-ext が書き出しで扱う (「よく使う書き方」の表)．
  ~oxq-qmd-mathfix.py~ は ox-quarto-ext 以外で作った qmd 用の後処理．
- 空行なしで隣り合う文と数式の環境は，qmd でも 1 つの段落のまま書き出す (tex で数式の後の文が字下げされない．~ox-quarto-ext-math-join~)．
  LaTeX の原稿の ~%~ 行を org のコメント行 (~# …~) に移したときは，init で ~(setq ox-quarto-ext-math-join-comments t)~ にすると
  コメント行をはさむ段落・数式もつながる．
- ~oxq-mathjax-check.py~ は qmd でも名前の無い数式の環境 (~\begin{align*}~ など) を検査する．org では ~* COMMENT~ の節，
  コメント行，comment / example / src ブロックの中は検査しない．

* カスタマイズ
- *front matter*: talk-*.yaml / lecture-*.yaml の違いは配色の 1 行 (と dracula の highlight-style，lecture-dracula の title-bg) だけ (talk-logo は見出しも logo-deck)．
  自分用に変えるときは ~_quarto/yaml/~ の yaml をプロジェクトにコピーし，SETUPFILE も複製して ~#+QUARTO_FRONTMATTER:~ を書き換える．
- *テーマ*: yaml の ~theme:~ に構造 (~oerreveal.scss~)・配色 (~*-palette.scss~)・修飾 (~*-deck.scss~)・機能の順に並べる．
  文字の大きさ・図の高さ・callout などの変数と，palette や deck の書き方は [[file:_quarto/README.md][_quarto/README.md]]．
- *ロゴ*: talk-logo の見出しのロゴは既定では主色の縦棒．自分のロゴや組織の校章を使うときは，
  ~_quarto/local/~ (git に入れないフォルダ) に scss と yaml を置く．手順は [[file:_quarto/local/README.md][_quarto/local/README.md]]．
- *書き出し*: ox-quarto-ext の変数 (実行する言語，~:notitle:~ の属性，構造テンプレートなど) は
  [[file:lisp/ox-quarto-ext/README.md][lisp/ox-quarto-ext/README.md]]．
