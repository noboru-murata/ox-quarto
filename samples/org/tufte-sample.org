* COMMENT メモ
- 手本は Quarto のギャラリーの Tufte handout 風の例 (page-layout/tufte)
- 脚注・引用の書誌・図の見出しは yaml の指定 (reference- / citation- / fig-cap-location: margin) だけで余白に出る．表の見出しは表の上
- 図を余白に: チャンクに ~#+ATTR_QUARTO: :column "margin"~
- 任意の内容を余白に: ~#+begin_column-margin~ (構造テンプレート ~<cm~)
- 本文と余白をまたぐ幅の図: チャンクに ~#+ATTR_QUARTO: :column "page-right"~．見出し (fig-cap) は付けない (LaTeX では余白に置かれて見えなくなる)
- PDF は LaTeX (lualatex) で作る．html も同じ org から作れる (余白は grid の margin-width)
- 書誌を余白に出すと (citation-location: margin)，文書の最後の参考文献の一覧は作られない
- 番号のない余白の注 ~[…]{.aside}~ は LaTeX では marginnote になり，余白の脚注 (sidenote) と重なることがあるので使っていない

* はじめに
この文書は，Edward Tufte の本や配布資料に見られる組版 [cite:@Tufte_2001_VisualDisplayQuantitative] にならい，
本文の右に広い余白を取って，脚注や図の見出し，小さな図をそこに置く形の見本である．
読み手は本文から目を離さずに補足を見られる[fn:sidenote]．

Quarto はこの形を html と PDF の両方で作れる．
ここでは Org で書き，ox-quarto で qmd に書き出して Quarto で仕上げる．
原稿とコードを一つにまとめる考え方 [cite:@Knuth_1984_LiterateProgramming] は，
R Markdown [cite:@Xie_etal_2018_RMarkdownDefinitive] を経て Quarto に受け継がれている．

* 余白に置くもの
** 脚注と引用
脚注は本文の下ではなく，参照した行の横の余白に出る[fn:margin]．
引用した文献の書誌も，本文中の (著者, 年) の横の余白に出る．
書誌を余白に出すとき，Quarto は文書の最後に参考文献の一覧を作らない．

** 余白の図
#+name: fig-margin
#+ATTR_QUARTO: :column "margin" :fig-cap "噴出の長さの分布 (faithful)" :fig-width 3 :fig-height 2.4
#+begin_src R
  library(ggplot2)
  ggplot(faithful, aes(eruptions)) +
    geom_histogram(bins = 20, fill = "#0B7558", colour = "white") +
    labs(x = "噴出の長さ [分]", y = "回数") +
    theme_minimal(base_size = 14)
#+end_src

小さな図は余白に置ける (@fig-margin)．
間欠泉の噴出の長さは，2 分前後と 4 分半前後の二つの山に分かれる．
本文の幅を狭く保ったまま，図を文の横に添えられるのがこの形の利点である．

** 余白の文と数式
#+begin_column-margin
微分積分学の基本定理から，\(x \in [a, b]\) について
\[\frac{d}{dx}\left(\int_a^x f(u)\,du\right) = f(x).\]
#+end_column-margin

~#+begin_column-margin~ で囲んだ内容は，文でも数式でもそのまま余白に置かれる．
右の余白の式は，本文の議論を補う定理を引いたものである．

* 本文の図と表
** 見出しを余白に置く図
#+name: fig-scatter
#+ATTR_QUARTO: :fig-cap "噴出の長さと次の噴出までの待ち時間．直線は最小二乗による回帰直線"
#+begin_src R
  ggplot(faithful, aes(eruptions, waiting)) +
    geom_point(colour = "#0B7558", alpha = 0.6) +
    geom_smooth(method = "lm", formula = y ~ x, colour = "#C2410C", se = FALSE) +
    labs(x = "噴出の長さ [分]", y = "待ち時間 [分]") +
    theme_minimal(base_size = 11)
#+end_src

本文の幅の図でも，見出しは余白に出る (@fig-scatter)．

** 余白まで広げた図
#+ATTR_QUARTO: :column "page-right" :fig-width 8 :fig-height 2.4
#+begin_src R
  ggplot(data.frame(i = 1:100, w = faithful$waiting[1:100]), aes(i, w)) +
    geom_line(colour = "#0B7558") + geom_point(colour = "#0B7558", size = 1) +
    labs(x = "回", y = "待ち時間 [分]") +
    theme_minimal(base_size = 11)
#+end_src

横に長い図は ~:column "page-right"~ で本文と余白をまたいで置ける (上の図は最初の 100 回の待ち時間の推移)．
余白が残らないので見出しは付けない (付けても LaTeX では見出しが余白に置かれて見えなくなる)．
待ち時間は長短を交互に繰り返すことが多い．

** 表
#+name: tbl-summary
#+ATTR_QUARTO: :tbl-cap "噴出の長さと待ち時間の要約 (faithful)"
#+begin_src R
  knitr::kable(
    data.frame(
      項目 = c("噴出の長さ [分]", "待ち時間 [分]"),
      平均 = sapply(faithful, mean),
      標準偏差 = sapply(faithful, sd),
      最小 = sapply(faithful, min),
      最大 = sapply(faithful, max),
      row.names = NULL),
    digits = 2)
#+end_src

表の見出しは表の上に置く (@tbl-summary)．余白に置くと Quarto 1.10 の LaTeX では組めないため．
